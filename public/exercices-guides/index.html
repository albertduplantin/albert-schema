Exercices guidés et mode classe pour l’enseignement

Albert Schema Studio propose des exercices guidés : l’énoncé s’affiche à côté du schéma, l’élève pose les composants, les câble et simule, et l’application vérifie chaque étape.

Pour l’enseignant

  • Un mode classe : l’élève rejoint la classe avec un lien, l’enseignant suit la progression avec le code de classe, sans compte.
  • Des exercices à publier soi-même depuis l’administration, avec niveau, durée et consignes.
  • Des exemples de la galerie pour projeter un circuit en cours : départ moteur, inversion de sens de marche, cycles pneumatiques, banc hydraulique.
  • Des boutons d’explication ⓘ à poser sur le schéma : un clic affiche le texte du professeur à côté du bouton.

Pour l’élève

Pas de compte à créer : les schémas restent dans le navigateur, avec une sauvegarde en ligne facultative par code de reprise. Fonctionne hors connexion une fois chargé.
